# Actividad — Pandas y Matplotlib

Resolución de la actividad de Ciencia de Datos: importación de datos con **Pandas** desde múltiples formatos y visualización con **Matplotlib**.

## Contenido

- `Ejercicios_Pandas_Matplotlib.ipynb` — notebook con ambos ejercicios resueltos y ejecutados (código, resultados y gráficos).
- `ventas.csv`, `clientes.json`, `inventario.xlsx` — datos de ejemplo para el Ejercicio 1 (importación y combinación de fuentes).
- `Automobile.csv` — dataset de autos para el Ejercicio 2 (inspección y visualización con Matplotlib).

## Ejercicio 1
Carga de ventas (CSV), clientes (JSON) e inventario (Excel) con Pandas, y combinación de las tres fuentes en un único DataFrame.

## Ejercicio 2
Análisis exploratorio del dataset de autos: gráfico de dispersión (mpg vs weight), histograma de mpg, boxplots (cylinders y origin) y gráfico de barras (model_year por origin).
